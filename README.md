Optical Camera Communication Development Kit (OCC devkit)

Tools for building OCC networks using off-the-shelf open-source hardware

Currently, we provide a code for live demonstration of OCC running on a Raspberry Pi 5 with camera V3 module. It let's the user select a pixel and plot the signal over time while the system looks into the received signal buffer searching for clusters of pulse amplitude modulation symbols, estimates the signal quality by means of signal-to-noise ratio and bit-error rate.
